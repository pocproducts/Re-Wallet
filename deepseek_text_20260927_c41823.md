PARTE 1 — CONTEXTO DEL PRODUCTO
1.1 Visión

BestPath Wallet es una wallet no cripto para usuarios cotidianos. La promesa central es:

    "Tu dinero, siempre creciendo. Sin frases semilla. Sin comisiones ocultas."

El producto elimina toda fricción cripto: no hay seed phrases, no hay selección de red, no hay gas visible, no hay jerga técnica. El usuario ve dólares, no tokens. Ve rendimiento, no APY de pools.
1.2 Evolución por versiones

v0.1 — Wireframes y Design System
Documento de especificación textual. 7 pantallas definidas con layout, jerarquía, componentes, microcopy exacto, estados y motion. Design system completo con tokens (colores, tipografía, espaciado, radios, sombras, motion) y 12 componentes base. Fase 1: flujo de rendimiento (onboarding → añadir dinero → procesamiento → home con saldo).

v0.2 — Prototipo funcional con estado
Primera implementación HTML/CSS/JS. Arquitectura con namespace BP: config, utils, store (localStorage), api (simulada), router (pila con transiciones), screens, ui (toast, banner, sheet, biométrico simulado), flow (lógica de negocio), actions (delegación de eventos). Passkey simulado con overlay de 1.2s. Rendimiento automático con ticker cada 9s. Persistencia en localStorage con versionado de esquema.

v0.3 — Fase 2: Enviar, Recibir, Actividad
Tres flujos nuevos. Enviar con selección de destinatario (contactos + input libre), monto con validación de saldo, confirmación y procesamiento parametrizable. Recibir con QR generado determinísticamente, tag copiable y navigator.share. Actividad con filtros (Todos / Envíos / Depósitos / Rendimiento) y agrupación por fecha (Hoy / Ayer / Esta semana / Anteriores). Detalle de movimiento en sheet. Migración de estado 0.2 → 0.3.

v0.4 — Fase 3: Ecosistema cerrado
Extensión del ecosistema consumer + payment. Recibir refactorizado de sheet a pantalla con tabs: Mi tag (QR + copiar + compartir) y Pedir monto (link de cobro bestpath.app/pay/ana/50). Envío externo con toggle Contacto/Dirección, validación ETH/Solana y warning rojo. Yield detail con tasa, proyección anual y chart de 7 días. Settings como pantalla completa: Perfil, Contactos (CRUD con límite de 20), Seguridad, Avanzado (modo avanzado toggle), Reset demo. Contactos con avatar por inicial y color determinístico. Migración de estado 0.3 → 0.4.

v0.5 — Ajustes de perfil y fix de navegación
Rediseño del perfil: cabecera en 2 columnas (foto circular a la izquierda, nombre + tag en dos filas a la derecha). Eliminación del modo avanzado de la UI (el código lo mantiene internamente por si se reactiva). Cierre de sesión real: confirmación → session:false → pantalla de login (passkey modo login) si el usuario ya completó onboarding, o welcome si no. Login con "Hola de nuevo", Face ID, PIN y "Usar otra cuenta". Fix del tab bar: la lista de actividad y los panes de recibir ahora usan flex:1;min-height:0 para que el tabbar quede pegado abajo como en Inicio y Cuenta. Navegación entre tabs con Router.replace() en vez de Router.go() para que las 3 tabs se sientan iguales (sin apilar en el historial).

1.4 Decisiones de producto clave

    Sin selección de red: el usuario nunca elige entre Ethereum, Polygon o Solana. El backend decide.

    Sin frases semilla: passkey + embedded wallet. El usuario nunca ve una seed.

    Sin gas visible: transacciones patrocinadas. El usuario nunca paga gas.

    Yield pasivo: el dinero genera rendimiento automáticamente. No hay staking manual.

    Link de cobro: bestpath.app/pay/{tag}/{monto} — compartible por WhatsApp, sin app del receptor.

    Modo avanzado apagado por default: el 90% nunca lo toca. El 10% que lo toca, sabe lo que hace.

    Custodia con proveedor: Privy/Turnkey abstraen la key. El usuario nunca la ve.

    Reset demo eliminado de UI: reemplazado por Cerrar sesión. Para debug: BP.debug.reset().

const Router = BP.router = {
  routes: {}, stack: [], current: null, busy: false,
  register(name, config){ Router.routes[name] = Object.assign({ render: () => '', transition: 'forward', replaceable: false }, config); return Router; },
  go(name, opts = {}){
    const route = Router.routes[name];
    if (!route){ console.warn('[BP] Ruta desconocida:', name); return; }
    if (Router.busy) return;
    const transition = opts.transition || route.transition;
    const replace = opts.replace || route.replaceable;
    Router.busy = true;
    const next = document.createElement('section');
    next.className = 'screen'; next.dataset.screen = name;
    next.innerHTML = `<div class="screen__inner">${route.render(opts.params || {})}</div>`;
    const prev = Router.current;
    if (prev){
      prev.classList.add(transition === 'forward' ? 'leave-forward' : transition === 'back' ? 'leave-back' : 'leave-fade');
      const prevEl = prev; setTimeout(() => prevEl.remove(), 420);
    }
    next.classList.add(transition === 'forward' ? 'enter-forward' : transition === 'back' ? 'enter-back' : 'enter-fade');
    screensEl.appendChild(next);
    if (replace && Router.stack.length) Router.stack[Router.stack.length - 1] = name;
    else Router.stack.push(name);
    Router.current = next;
    next.scrollTop = 0;
    if (location.hash !== '#/' + name) history.pushState({ screen:name }, '', '#/' + name);
    if (route.onMount) requestAnimationFrame(() => route.onMount(next, opts.params || {}));
    setTimeout(() => { Router.busy = false; }, 420);
    return next;
  },
  back(){
    if (Router.stack.length <= 1) return;
    Router.stack.pop();
    const target = Router.stack[Router.stack.length - 1];
    Router.stack.pop();
    Router.go(target, { transition:'back' });
  },
  replace(name, opts = {}){ Router.go(name, Object.assign({}, opts, { replace:true })); },
  init(fallback){
    const fromHash = (location.hash || '').replace('#/','');
    const start = Router.routes[fromHash] ? fromHash : fallback;
    Router.go(start, { transition:'fade' });
    window.addEventListener('popstate', () => {
      const name = (location.hash || '').replace('#/','');
      if (!Router.routes[name]) return;
      if (name === Router.current?.dataset.screen) return;
      Router.stack.pop(); Router.stack.pop();
      Router.go(name, { transition:'back' });
    });
  }
};

function groupByDate(movements){
  const now = new Date();
  const startOfToday = new Date(now.getFullYear(), now.getMonth(), now.getDate()).getTime();
  const startOfYesterday = startOfToday - 86400000;
  const startOfWeek = startOfToday - 7 * 86400000;
  const buckets = { today: [], yesterday: [], week: [], older: [] };
  movements.forEach(m => {
    if (m.at >= startOfToday) buckets.today.push(m);
    else if (m.at >= startOfYesterday) buckets.yesterday.push(m);
    else if (m.at >= startOfWeek) buckets.week.push(m);
    else buckets.older.push(m);
  });
  const labels = { today:'Hoy', yesterday:'Ayer', week:'Esta semana', older:'Anteriores' };
  return Object.keys(buckets).filter(k => buckets[k].length).map(k => ({ label:labels[k], items:buckets[k] }));
}

const Flow = BP.flow = {
  _yieldTimer: null,
  _timeTimer: null,

  async addMoney(amount, asset){
    Router.go('processing', { transition:'fade', params:{ type:'deposit' } });
    const root = Router.current;
    const subEl = root.querySelector('[data-processing-sub]');
    const actionsEl = root.querySelector('[data-processing-actions]');
    const progressEl = root.querySelector('[data-progress]');
    const t1 = setTimeout(() => { if (subEl) subEl.innerHTML = 'Casi listo...'; }, 3000);
    const t2 = setTimeout(() => { if (subEl) subEl.innerHTML = 'Esto puede tardar un poco más de lo normal.<br>Puedes dejar la app abierta.'; }, 10000);
    const [result] = await Promise.all([
      BP.api.addMoney(amount, asset),
      U.wait(U.rand(BP.config.processingMinMs, BP.config.processingMaxMs))
    ]);
    clearTimeout(t1); clearTimeout(t2);
    if (!result.ok){
      if (subEl) subEl.innerHTML = 'Algo no salió como esperábamos.<br>Puedes reintentar.';
      if (progressEl) progressEl.classList.add('paused');
      if (actionsEl) actionsEl.innerHTML = `
        <div class="dual" style="max-width:320px;margin:0 auto">
          <button class="btn btn--secondary btn--lg" data-action="back">Volver</button>
          <button class="btn btn--primary btn--lg" data-action="retry-add" data-amount="${amount}" data-asset="${U.esc(asset)}">Reintentar</button>
        </div>`;
      return;
    }
    const s = Store.get();
    const newBalance = Number((s.balance + result.amount).toFixed(4));
    Store.set({
      balance: newBalance,
      movements: [{ id:U.uid(), type:'deposit', title:`Añadiste ${U.money(result.amount)}`, amount:result.amount, at:Date.now() }, ...s.movements],
      lastYieldAt: Date.now()
    });
    U.haptic(12);
    Router.replace('home', { transition:'fade' });
  },

  async sendMoney(){
    const s = Store.get();
    if (s.balance <= 0){ UI.toast('Añade dinero primero para poder enviar.', 'info'); return; }

    const recipient = await Flow._pickRecipient();
    if (!recipient) return;

    const payload = await Flow._pickAmount(recipient);
    if (!payload) return;

    const confirmed = await UI.confirm({
      title:'¿Confirmás el envío?',
      message:`Vas a enviar ${U.money(payload.amount)} a ${recipient.name}${recipient.type==='address'?' ('+recipient.tag+')':''}.`,
      confirmLabel:'Enviar',
      cancelLabel:'Cancelar'
    });
    if (!confirmed) return;

    await Flow._processSend(recipient, payload.amount);
  },

  async _pickRecipient(){
    const s = Store.get();
    const recent = s.contacts.slice(0, 4);

    return UI.sheet({
      title:'Enviar dinero',
      content: `
        <div class="field">
          <input class="field__input" type="text" id="recipient-input" placeholder=" " autocomplete="off" data-recipient-input>
          <label class="field__label" for="recipient-input">Nombre, @usuario o correo</label>
        </div>
        <div class="field__helper" id="recipient-help">Escribí un @usuario, correo o teléfono.</div>
        <div class="divider"></div>
        <p class="t-micro t-tertiary" style="letter-spacing:.06em;margin-bottom:var(--space-2)">RECIENTES</p>
        <div class="stack stack-2" data-recent>${recent.map(c => contactRow(c)).join('')}</div>`,
      onMount(sheet, close){
        const input = sheet.querySelector('#recipient-input');
        const helpEl = sheet.querySelector('#recipient-help');
        const recentEl = sheet.querySelector('[data-recent]');

        recentEl.addEventListener('click', (e) => {
          const row = e.target.closest('[data-contact-id]');
          if (!row) return;
          const contact = s.contacts.find(c => c.id === row.dataset.contactId);
          if (contact){ U.haptic(8); close({ type:'contact', ...contact }); }
        });

        input.addEventListener('input', () => {
          const v = input.value.trim();
          if (!v){ helpEl.textContent = 'Escribí un @usuario, correo o teléfono.'; helpEl.style.color = ''; return; }
          const resolved = Flow._resolveRecipient(v);
          helpEl.textContent = `Enviar a ${resolved.name}`;
          helpEl.style.color = 'var(--color-accent-primary)';
        });

        input.addEventListener('keydown', (e) => {
          if (e.key === 'Enter'){
            const v = input.value.trim();
            if (v){ U.haptic(8); close(Flow._resolveRecipient(v)); }
          }
        });

        setTimeout(() => input.focus({preventScroll:true}), 400);
      }
    });
  },

  _resolveRecipient(value){
    const s = Store.get();
    const trimmed = String(value).trim();
    const lower = trimmed.toLowerCase();
    const clean = lower.startsWith('@') ? lower : '@' + lower;
    const match = s.contacts.find(c => c.tag.toLowerCase() === clean || c.name.toLowerCase().includes(lower));
    if (match) return { type:'contact', ...match };
    if (U.isEmail(trimmed)){
      return { type:'email', id:U.uid(), name:trimmed.split('@')[0], tag:trimmed, initials:trimmed[0].toUpperCase(), color:U.colorFrom(trimmed) };
    }
    const digits = trimmed.replace(/\D/g,'');
    if (digits.length >= 8){
      return { type:'phone', id:U.uid(), name:'Contacto ' + digits.slice(-4), tag:trimmed, initials:'#', color:'#A1A1A6' };
    }
    return { type:'tag', id:U.uid(), name:clean, tag:clean, initials:(clean[1] || '?').toUpperCase(), color:U.colorFrom(clean) };
  },

  async _pickAmount(recipient){
    let amount = 0;
    const s = Store.get();
    const max = s.balance;

    return UI.sheet({
      title:'Monto',
      content: `
        <div class="row" style="gap:12px;margin-bottom:20px">
          ${contactAvatar(recipient, 40)}
          <div class="grow" style="min-width:0">
            <div class="t-body-sm" style="font-weight:500">${U.esc(recipient.name)}</div>
            <div class="t-caption t-tertiary t-mono" style="overflow:hidden;text-overflow:ellipsis;white-space:nowrap">${U.esc(recipient.tag)}</div>
          </div>
        </div>
        <div class="amount-display">
          <div class="amount-display__value"><span>$</span>
            <input class="amount-display__input" type="text" inputmode="decimal" value="0.00" data-amount-input aria-label="Monto a enviar">
          </div>
        </div>
        <p class="t-body-sm t-tertiary text-center mb-6" data-balance-hint>${U.money(max)} disponibles</p>
        <button class="btn btn--primary btn--lg btn--block" data-submit disabled>Continuar</button>`,
      onMount(sheet, close){
        const input = sheet.querySelector('[data-amount-input]');
        const submit = sheet.querySelector('[data-submit]');
        const hint = sheet.querySelector('[data-balance-hint]');
        const sync = () => {
          const val = parseFloat(String(input.value).replace(',','.')) || 0;
          amount = val;
          const valid = val > 0 && val <= max;
          submit.disabled = !valid;
          if (val > max){ hint.textContent = 'Saldo insuficiente'; hint.style.color = 'var(--color-error)'; }
          else if (val > 0){ hint.textContent = `${U.money(max - val)} restantes`; hint.style.color = ''; }
          else { hint.textContent = `${U.money(max)} disponibles`; hint.style.color = ''; }
        };
        input.addEventListener('input', () => { input.value = input.value.replace(/[^\d.,]/g,''); sync(); });
        input.addEventListener('blur', () => { const v = parseFloat(String(input.value).replace(',','.')) || 0; input.value = v > 0 ? v.toFixed(2) : '0.00'; sync(); });
        input.addEventListener('focus', () => setTimeout(() => input.select(), 50));
        submit.addEventListener('click', () => { if (submit.disabled) return; U.haptic(10); close({ amount }); });
        setTimeout(() => { input.focus({preventScroll:true}); input.select(); }, 380);
        sync();
      }
    });
  },

  async _processSend(recipient, amount){
    Router.go('processing', { transition:'fade', params:{ type:'send', recipient, amount } });
    const root = Router.current;
    const subEl = root.querySelector('[data-processing-sub]');
    const actionsEl = root.querySelector('[data-processing-actions]');
    const progressEl = root.querySelector('[data-progress]');
    const t1 = setTimeout(() => { if (subEl) subEl.innerHTML = 'Casi listo...'; }, 2500);
    const [result] = await Promise.all([
      BP.api.sendMoney(amount, recipient),
      U.wait(U.rand(BP.config.sendMinMs, BP.config.sendMaxMs))
    ]);
    clearTimeout(t1);
    if (!result.ok){
      if (subEl) subEl.innerHTML = 'Algo no salió como esperábamos.<br>Podés reintentar.';
      if (progressEl) progressEl.classList.add('paused');

3.2 Privy — Passkey + Embedded Wallet

Privy resuelve las dos piezas más difíciles: autenticación WebAuthn y custodia de la key.

Passkey (WebAuthn)
Privy permite a los usuarios registrarse e iniciar sesión con passkey. El flujo es:

    Usuario toca "Usar Face ID" → loginWithPasskey() o signupWithPasskey()

    Privy invoca navigator.credentials.create() o .get() con challenge del server

    El dispositivo verifica biometría y devuelve la credencial

    Privy valida y crea la sesión

Para integrar una implementación de passkey existente, Privy recomienda usar los SDKs de SimpleWebAuthn, que proveen flujos simples de registro y autenticación

.

Embedded Wallet
Privy crea automáticamente una wallet embebida (EVM o Solana) cuando el usuario se autentica. La key se guarda en un TEE (Trusted Execution Environment) con Shamir Secret Sharing. El usuario nunca ve la key ni la seed.

En el dashboard de Privy:

    Habilitar "Automatically create embedded wallets on login"

    Seleccionar "EVM Wallets"

    Configurar la red default como Monad

Monad + Privy
Privy soporta Monad como chain EVM. La configuración es:

    chainId: 143 (Monad mainnet) o el chainId de testnet

    RPC URL de Monad (QuickNode, Alchemy, o el público)

    Privy inicializa la wallet embebida en la red default

Gas sponsorship
Privy tiene un motor de gas sponsorship que cubre las fees de transacción. Soporta Monad y Monad Testnet. El costo incluye el gas de red más una convenience fee del servicio

. Esto permite que el usuario nunca vea gas.

Pricing
Privy tiene free tier: 50K signatures y 100K transactions por mes. Planes pagos: Core $299/mes, Scale $499/mes

. Para hackathon, el free tier es más que suficiente.

3.6 Contrato de API
text

POST   /auth/register/begin          → challenge + options
POST   /auth/register/finish         → set-cookie session
POST   /auth/login/begin             → challenge + options
POST   /auth/login/finish            → set-cookie session
POST   /auth/logout                  → 204
GET    /me                           → user + wallet

GET    /wallet                       → { balance, currency }
GET    /wallet/movements?cursor=     → movements paginados
POST   /wallet/deposit-intent        → { address } | { onrampUrl }
POST   /wallet/send                  → idempotency-key required
POST   /wallet/request               → { url, id, amount }
GET    /wallet/request/:id           → request público

GET    /contacts
POST   /contacts
DELETE /contacts/:id

PATCH  /me/profile                   → { name }
PATCH  /me/recovery                  → { email, phone }

GET    /yield/summary                → { rate, earned, projected }
GET    /yield/history?days=7         → [{ date, value }]

POST   /webhooks/onramp              → firma verificada
POST   /webhooks/chain               → firma verificada

Formato de error uniforme:
json

{ "error": "insufficient_funds", "message": "Saldo insuficiente", "code": 402 }

Idempotencia: todos los POST de dinero requieren header Idempotency-Key: <uuid>. El server guarda la key por 24h y devuelve el mismo resultado.
