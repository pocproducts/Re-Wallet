[CONTEXTO DEL PRODUCTO]

BestPath Wallet es una wallet no cripto para usuarios cotidianos.
Promesa: "Tu dinero, siempre creciendo. Sin frases semilla.
Sin comisiones ocultas."

Reglas del producto que condicionan el backend:

- El usuario NUNCA ve frases semilla. Privy custodia la key.
- El usuario NUNCA selecciona red. El backend usa Monad.
- El usuario NUNCA ve gas. Pimlico lo patrocina.
- El usuario NUNCA ve jerga cripto. Solo dólares y rendimiento.
- El rendimiento es pasivo. El backend deposita en Aave V3.
- Los links de cobro son públicos. bestpath.app/pay/{id}

Hackathon objetivo: Monad Metropolis (deadline 13 oct 2026)
Track: Consumer Products & Payments

[SCHEMA DE POSTGRES — TODAS LAS TABLAS]

Usar Drizzle ORM. Tipos exactos:

users
  id                uuid PK default gen_random_uuid()
  privy_did         text UNIQUE NOT NULL      -- ID de Privy
  name              text NOT NULL
  tag               text UNIQUE NOT NULL      -- @ana, lowercase
  tag_normalized    text UNIQUE NOT NULL      -- ana (sin @)
  recovery_email    text
  recovery_phone    text
  avatar_color      text                      -- hex
  created_at        timestamptz default now()
  updated_at        timestamptz default now()

wallets
  id                uuid PK default gen_random_uuid()
  user_id           uuid FK users(id) UNIQUE NOT NULL
  address           text UNIQUE NOT NULL      -- EVM address de Privy
  balance           numeric(20,6) default 0   -- USDC, 6 decimales
  yield_started_at  timestamptz               -- cuándo empezó a rendir
  created_at        timestamptz default now()
  updated_at        timestamptz default now()

movements
  id                uuid PK default gen_random_uuid()
  wallet_id         uuid FK wallets(id) NOT NULL
  type              text NOT NULL             -- deposit|send|receive|yield
  amount            numeric(20,6) NOT NULL    -- + ingreso, - egreso
  title             text NOT NULL
  status            text default 'completed'  -- pending|completed|failed
  meta              jsonb default '{}'        -- tx_hash, recipient, etc
  created_at        timestamptz default now()
  INDEX (wallet_id, created_at DESC)

contacts
  id                uuid PK default gen_random_uuid()
  user_id           uuid FK users(id) NOT NULL
  name              text NOT NULL
  tag               text NOT NULL             -- @usuario o email o tel
  color             text                      -- hex
  initials          text
  created_at        timestamptz default now()
  UNIQUE (user_id, tag)
  INDEX (user_id)

sessions
  id                uuid PK default gen_random_uuid()
  user_id           uuid FK users(id) NOT NULL
  token_hash        text UNIQUE NOT NULL      -- hash del token
  expires_at        timestamptz NOT NULL
  created_at        timestamptz default now()
  revoked_at        timestamptz
  INDEX (user_id, expires_at)

idempotency_keys
  key               text PK                   -- header Idempotency-Key
  user_id           uuid FK users(id) NOT NULL
  endpoint          text NOT NULL
  response          jsonb NOT NULL
  created_at        timestamptz default now()
  expires_at        timestamptz NOT NULL      -- key + 24h

payment_requests
  id                text PK                   -- short id (nanoid 10)
  user_id           uuid FK users(id) NOT NULL
  amount            numeric(20,6) NOT NULL
  status            text default 'pending'    -- pending|paid|expired
  paid_by_user_id   uuid FK users(id)
  paid_movement_id  uuid FK movements(id)
  created_at        timestamptz default now()
  paid_at           timestamptz
  expires_at        timestamptz NOT NULL      -- created + 7d
  INDEX (user_id, created_at DESC)

yield_positions
  id                uuid PK default gen_random_uuid()
  wallet_id         uuid FK wallets(id) UNIQUE NOT NULL
  aave_atoken_bal   numeric(20,6) default 0   -- balance en aToken
  last_accrued_at   timestamptz
  created_at        timestamptz default now()
  updated_at        timestamptz default now()

yield_accruals
  id                uuid PK default gen_random_uuid()
  wallet_id         uuid FK wallets(id) NOT NULL
  amount            numeric(20,6) NOT NULL
  apy_bps           integer NOT NULL          -- basis points, ej 565
  accrued_for_date  date NOT NULL             -- día del accrual
  created_at        timestamptz default now()
  UNIQUE (wallet_id, accrued_for_date)
  INDEX (wallet_id, accrued_for_date DESC)

webhook_events
  id                uuid PK default gen_random_uuid()
  source            text NOT NULL             -- privy|monad|pimlico
  event_type        text NOT NULL
  payload           jsonb NOT NULL
  signature_valid   boolean NOT NULL
  processed_at      timestamptz
  error             text
  created_at        timestamptz default now()
  INDEX (source, event_type, created_at DESC)

gas_sponsorships
  id                uuid PK default gen_random_uuid()
  user_id           uuid FK users(id) NOT NULL
  tx_hash           text
  user_op_hash      text
  sponsored_amount  numeric(20,6)             -- costo del gas en USD
  status            text default 'pending'    -- pending|confirmed|failed
  created_at        timestamptz default now()
  INDEX (user_id, created_at DESC)

[ENDPOINTS — SOLO STUBS CON TIPOS]

Cada endpoint debe:
  - Tener su schema Zod de request
  - Tener su tipo de response en packages/shared
  - Devolver un stub { ok: true, data: null } con TODO
  - Estar montado en routes/index.ts

Auth:
  POST   /auth/register/begin     → { challenge, options }
  POST   /auth/register/finish    → { user, wallet } + set-cookie
  POST   /auth/login/begin        → { challenge, options }
  POST   /auth/login/finish       → { user, wallet } + set-cookie
  POST   /auth/logout             → 204
  GET    /auth/session            → { user, wallet } | 401

User:
  GET    /me                      → { user, wallet, yieldSummary }
  PATCH  /me/profile              → { name } → { user }
  PATCH  /me/recovery             → { email, phone } → { user }

Wallet:
  GET    /wallet                  → { balance, currency, yieldStartedAt }
  GET    /wallet/movements        → { items: Movement[], cursor }
  POST   /wallet/deposit-intent   → { address } | { onrampUrl }
  POST   /wallet/send             → Idempotency-Key required
                                  → { movement, newBalance }
  POST   /wallet/request          → { url, id, amount }
  GET    /wallet/request/:id      → { request } (público, sin auth)

Contacts:
  GET    /contacts                → { items: Contact[] }
  POST   /contacts                → { contact }
  DELETE /contacts/:id            → 204

Yield:
  GET    /yield/summary           → { rate, earned, projected }
  GET    /yield/history?days=7    → { items: YieldAccrual[] }

Webhooks:
  POST   /webhooks/privy          → firma verificada, 200
  POST   /webhooks/chain          → firma verificada, 200
  POST   /webhooks/pimlico        → firma verificada, 200

Health:
  GET    /health                  → { ok, version, uptime }
  GET    /ready                   → { db: ok, rpc: ok, privy: ok }
